### 1. 历史上下文分析师 【新增】
```
# 输入：历史章节内容、角色发展轨迹、世界
观设定
# 输出：历史上下文摘要

输出内容：
- 历史章节核心情节概要（200字）
- 主要角色当前状态（性格、情绪、关系）
- 未解决的伏笔和悬念（2-3个）
- 世界观已确立的规则和设定
- 本章节需要承接的关键要素
- 风格基调参考（语言风格、叙事节奏）
```
### 2. 对话分析师 【增强】
```
# 输入：新对话内容 + 历史上下文摘要 + 世
界观 + 人物设定
# 输出：对话分析报告

输出内容：
- 新对话的核心情节要点
- 与历史章节的关联点
- 对话中涉及的角色行为是否符合历史设定
- 需要特别注意的世界观要素
- 对话的情感基调
- 建议的叙事重点
```
### 3. 剧情规划师 【增强】
```
# 输入：对话分析报告 + 历史上下文摘要
# 输出：剧情规划方案

输出内容：
- 章节标题建议
- 叙事视角和节奏
- 情节发展大纲（3-5个关键节点）
- 如何承接历史悬念
- 如何处理角色发展
- 场景转换方案
- 对话融入方式
```
### 4. 写作手 【增强】
```
# 输入：剧情规划方案 + 历史章节风格参考 
+ 对话内容
# 输出：章节草稿

输出内容：
- 完整的章节内容（Markdown格式）
- 符合历史章节的语言风格
- 自然处理章节过渡
- 保持角色性格一致
- 融入对话内容
```
### 5. 修饰包装师 【增强】
```
# 输入：章节草稿 + 历史章节内容
# 输出：最终章节

处理内容：
- 检查与历史章节的风格一致性
- 优化章节间的衔接
- 删除冗余内容
- 修复逻辑不流畅的地方
- 添加必要的修饰描写
- 确保 Markdown 格式规范
- 最终质量把控
```
